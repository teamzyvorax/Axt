# ZYVORA Domains

Premium responsive domain-management dashboard inspired by the supplied reference design.

## Included

- Responsive mobile + desktop UI
- ZYVORA dark/neon visual system
- Domain status card
- Add-subdomain modal
- Manage-domain modal
- Copy-domain action
- Renewal/status interactions
- GitHub Pages deployment workflow

## GitHub Pages

The repository includes `.github/workflows/pages.yml` and deploys the static site through GitHub Actions once Pages is enabled for the repository.
